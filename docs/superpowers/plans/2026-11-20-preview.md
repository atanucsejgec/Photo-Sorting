# Preview mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Preview mode that shows the remaining files one at a time (image, PDF, video, audio, text, or an info card) and moves each one with N (Not needed) or M+digit (one of 10 listed folders). Every move is journalled for Undo.

**Architecture:**
- Core session logic lives in `modes/preview.py`: listing files, sorting them into kinds, moving, putting back, and journalling. It has no Qt.
- The viewers live in `ui/preview_viewers.py`, one widget per kind.
- The page, the folder overlay and the slot editor live in `ui/preview_page.py`. The flow lives in `ui/flows/preview.py` and wires the mode in.

**Tech Stack:** Python 3.12, PySide6 6.12 Essentials and Addons (QtMultimedia), pypdfium2 for PDFs (owner approved; every pdfium call under one lock), and the existing journal, executor and imageinfo.

**Spec:** docs/superpowers/specs/2026-11-20-preview-design.md (binding; read it whole).

## Global Constraints
- The mode key is `"preview"`, the label "Preview", kind `"preview"` and the Home hint "Look at each file, move it". It comes right after `pick_faces` in MODES.
- The Not needed folder is `<root>/Not needed`. Its name is the constant `NOT_NEEDED = "Not needed"`.
- There are 10 slots. Keys 1–9 are slots 1–9 and key 0 is slot 10. They are stored in `Settings.preview_folders: list[str | None]` of length 10, holding absolute paths. A bad value loads as 10 Nones.
- Moves stay inside the root: a target outside it is refused with the spec's message.
- Never delete and never overwrite: use `plan.TargetAllocator` (or whatever `execute` uses) together with `executor.move_file`.
- The journal is one RunJournal per session (mode "preview"), created at the first move. Each move is `record_intent` → `move_file` → `record_done`. A put-back is a reverse move recorded the same way. `finish("done")` is called at the end, and empty folders made by the session are removed as `executor._remove_empty_dirs` does.
- Keys: ←/→ file; Shift+←/→ ±10 s; Space play/pause; S speed cycle 1×→2×→4×; +/− and Ctrl+wheel zoom; F fit; ↑/↓/PgUp/PgDn scroll; N; M then 1–9/0, Enter = Other folder…, Esc = close the overlay; L edits the folders; Ctrl+Z puts back; O opens with the system app; Esc asks to leave.
- No new downloads. Tests make their media themselves (wave, QPdfWriter, ffmpeg if it's present). Tests that need `pdftoppm` or `ffmpeg` are skipped when the tool is missing.
- Tests use tmp_path and the conftest's isolated data dir. Never touch `/run/media` or the real `~/.local/share/photo-sorter`.
- Commits: author Atanu Biswas <154270931+atanucsejgec@users.noreply.github.com>, no Co-Authored-By line.
- Heavy runs go through: `flock <scratchpad>/heavy.lock systemd-run --user --scope -q -p MemoryMax=6G -p MemorySwapMax=0 timeout 900 …`

## Review Focus
1. **Put back after the folder made for the first move.** Ctrl+Z all the way back, then Undo of the run, must leave the tree byte for byte as before, with no left-over empty "Not needed" folder. Task 1 tests this.
2. **The target already has a file with the same name.** The move gets a new name and never overwrites. Task 1 tests this.
3. **A file that's playing.** The player must let go of it before the move (on Linux the move works anyway, but the player must not hold a stale source and then error). Task 3 tests this.
4. **A file that disappears or fails to move.** It shows an error, the file stays in the list, and the session goes on. Tasks 1 and 3 test this.
5. **A slot folder that is inside the root but deleted since.** Pressing its number re-creates it (journalled as a created folder) rather than failing. Task 1 tests this.

### Task 1: Core — `modes/preview.py`, settings, mode entry

**Files:**
- Create: `src/photosort/modes/preview.py`
- Modify: `src/photosort/settings.py` (add `preview_folders`)
- Modify: `src/photosort/modes/__init__.py` (add the MODES entry and the ModeSpec kind "preview"; its find function raises NotImplementedError, like pick_faces)
- Test: `tests/test_preview.py`, `tests/test_settings.py`

**Interfaces (produced):**
- `NOT_NEEDED = "Not needed"`; `SLOTS = 10`
- `FileKind = Literal["image", "pdf", "video", "audio", "text", "other"]`
- `file_kind(path: Path) -> FileKind`. It goes by extension: images are what `imageinfo` opens; video uses `media.kind == "video"`; audio is mp3/m4a/aac/wav/flac/ogg/opus/wma/amr; text is txt/md/csv/tsv/json/log/xml/ini/yaml/yml/srt.
- `preview_files(root: Path, include_subfolders: bool, slots: list[str | None]) -> list[str]`. It returns root-relative POSIX paths, sorted by folder and then by natural name (case-folded, digit runs compared as numbers). It skips `Not needed/**`, the slot folders inside the root, and `scanner.skipped_folder`.
- `slot_problem(root: Path, folder: str | None) -> str | None`. It returns None when the slot is usable, otherwise exactly "Slot is empty" or "<name> isn't inside this folder". (The UI puts the slot number in front.)
- `inside_root(root: Path, folder: Path) -> bool`. Both sides are resolved, and the root itself counts as inside.
- `class PreviewSession(root: Path, include_subfolders: bool)`:
  - `move(rel: str, target_folder: Path) -> str` returns the new rel. The journal is created on the first call. The target must be inside the root, otherwise ValueError with the spec's message. Missing parent folders are created and journalled. A missing source raises FileNotFoundError.
  - `put_back() -> str | None` returns the rel that came back, or None if nothing is left to put back. It records a reverse move. If the original path is now taken, it allocates a new name.
  - `moved: list[tuple[str, str]]` holds the live (src, dst) pairs, in order.
  - `counts() -> tuple[int, int]` gives (to Not needed, to other folders) for the live moves.
  - `finish() -> str | None` removes empty folders that the session made, calls `finish("done")`, and returns run_id (None if nothing ever moved). It can be called more than once safely.
- Settings gains `preview_folders: list[str | None]` (10 long, validated).

### Task 2: Viewers — `ui/preview_viewers.py`

**Files:**
- Create: `src/photosort/ui/preview_viewers.py`
- Test: `tests/test_ui_preview_viewers.py`

**Interfaces (produced):** every viewer is a QWidget with:
- `load(path: Path) -> None`
- `release() -> None`: stops playback, clears the source and drops any image.
- `handle_key(event: QKeyEvent) -> bool`: True if used.
- `keys() -> list[tuple[str, str]]`: the strip entries for this kind.
- A `failed = Signal(str)` signal: the page then shows the info card.

The classes:
- `ImageViewer`: decodes through `imageinfo.open_image` on the pool, with a generation tag. Zoom from 10 % to 800 %, F fits, +/−/Ctrl+wheel, drag to pan, ↑/↓ scroll. It has `zoom() -> float`.
- `PdfViewer`: `pdfinfo` for the page count and `pdftoppm` for rendering, through `subprocess.run` with a timeout of 30 s on the pool. Only the pages in view and one ahead are rendered. Zoom maps to dpi (72·zoom·devicePixelRatio, capped at 400 dpi). It has `page_text() -> "page N of M"`.
- `MediaViewer(video: bool)`: QMediaPlayer, QAudioOutput, QVideoWidget (for video) or a music icon (for audio), a slider and "m:ss / m:ss". It has `play_pause()`, `seek(delta_ms)`, `cycle_speed()`, `set_speed(r)` with r in {1.0, 2.0, 4.0}, and 3 speed buttons with the current one checked. It never autoplays. The speed is held class-wide, so it is kept from one file to the next.
- `TextViewer`: a read-only monospaced QPlainTextEdit. It reads at most 1 MB as UTF-8 with replacement. +/− change the font size.
- `InfoCard`: name, type, size, modified date and full path, plus an "Open with the system app (O)" button that uses QDesktopServices. It has `set_message(text)` for "Can't show this PDF" and similar.

### Task 3: Page, folder overlay, slot editor, flow, Home tile

**Files:**

- Modify: `src/photosort/ui/main_window.py` (build the page, register the flow for kind "preview"), `src/photosort/ui/home_page.py` (TILES hint), `src/photosort/ui/icons.py` (an icon; reuse an existing icon file)
- Test: `tests/test_ui_preview.py`

**Interfaces:** consumes Task 1 (`PreviewSession`, `preview_files`, `file_kind`, `slot_problem`, `inside_root`, `NOT_NEEDED`, `SLOTS`) and Task 2 (the viewers' contract).

**Behaviour, as in the spec:**
- The top line reads "12 of 340 · name · size · date", then the folder relative to the root, then "page N of M" for a PDF.
- The side panel lists the slots, with greyed ones outside the root. The help strip shows the current kind's keys plus the page keys.
- Moves are queued on one worker in order. The next file shows at once. On failure, the page message line shows "Couldn't move <name>: <error>" and the file is put back into the list at its old position.
- The player is `release()`d before a move of the file it is showing, and on every file change.
- Leaving with Esc asks "Leave Preview?" with Leave focused. Leaving, the last file, or the window closing calls `session.finish()`. If anything moved, the Done page shows "Moved N files: X to Not needed, Y to folders", with Undo working as for other runs (`window` after-run patterns). If nothing moved, it goes back Home.
- The folder pick and "Include subfolders?" are the same as other modes, and `bring_in` is non-strict before listing. An empty list gives the summary page with "No files to preview", like `NO_FACES`.
